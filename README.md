# Dress Evidence Review

드레스 투어의 스케치, 두 사람의 의견, 실제 피팅 사진과 외부 후보를 근거에 따라 연결하는 Codex 스킬입니다.

세 업체의 드레스 비교 사이트를 만들면서 겪은 기록 순서 정정, 손글씨 전사, 캐러셀 중복 수집, 릴스 누락, 병렬 검토의 경험을 재사용 가능한 지침으로 정리했습니다.

## 하는 일

1. 사용자에게 확인된 업체와 피팅 순서로 사진과 스케치를 연결합니다.
2. 두 사람의 의견을 분리하고, 판독 불가와 디자인 관찰·개인 감상을 구분합니다.
3. 사진의 외관과 출처가 명시한 소재 정보를 별도로 기록합니다.
4. 외부 후보에 출처, 유사점, 차이점, 미확인 부분을 남깁니다.
5. 게시물 발견·다운로드·시각 검토·분류·사이트 반영 상태를 구분합니다.
6. 기존 사이트에 사진을 추가할 때 번호와 메모 연결을 유지합니다.

같은 베일이 보여도 같은 드레스라고 확정하지 않습니다. 찾지 못했거나 판단할 수 없는 경우도 결과에 포함합니다.

## 설치

저장소를 내려받은 뒤 `skills/dress-evidence-review` 폴더를 자신의 Codex 스킬 디렉터리에 복사합니다. 기본 위치는 `~/.codex/skills/`입니다. `CODEX_HOME`을 별도로 설정했다면 해당 디렉터리의 `skills/`를 사용합니다.

```text
~/.codex/skills/dress-evidence-review/
├── SKILL.md
├── agents/openai.yaml
├── references/review-records.md
└── scripts/check_review.py
```

기존 동일 이름의 스킬이 있으면 먼저 비교합니다. 설치 후 새 대화에서 `$dress-evidence-review`로 호출합니다.

## 사용 예시

```text
$dress-evidence-review
첨부한 두 기록은 두 사람이 같은 네 벌을 기록한 것이다.
사용자가 확인한 업체별 피팅 순서대로 묶고 두 사람 의견을 구분해줘.
스케치 두 원본의 전체보기를 제공하고 실제 피팅 사진을 옆에 배치해줘.
인스타그램·블로그 후보는 출처와 일치·불일치 근거를 붙여 아래에 접어둬.
같은 제품으로 확정할 수 없는 것은 후보로 표시해줘.
```

병렬 검토가 필요하면 게시물 구간 또는 매체별로 나눠 달라고 요청합니다. 결과 파일은 작업자별로 분리하고 한 담당자가 병합합니다.

## 검토 기록 검사

Python 3 표준 라이브러리만 사용합니다. [기록 형식](skills/dress-evidence-review/references/review-records.md)에 맞춘 JSON을 검사합니다.

```sh
python skills/dress-evidence-review/scripts/check_review.py review.json
```

중복 ID, 중복 미디어 키, 캐러셀 장수·순서 불일치, 미검토 사진의 완료 처리, 근거 없는 확정 표시 등을 확인합니다. 정상 종료 코드는 0, 기록 오류는 1, 읽기·형식 오류는 2입니다.

이 검사는 이미지 동일성이나 손글씨 판독의 정확성을 보증하지 않습니다. 릴스의 시간대별 장면 검토도 모든 프레임을 검사했다는 뜻이 아닙니다.

## 범위와 공개 자료

이 저장소에는 작업 방법, 합성 예시, 검증 코드만 포함합니다. 개인 피팅 사진, 손글씨 원본, 수집한 SNS 사진, 계정 토큰, 기존 사이트의 전체 데이터는 포함하지 않습니다. 과정 정리 글의 수치는 당시 작업 기록이며 현재 계정이나 갤러리의 실시간 수치가 아닙니다.

스킬 자체는 자동 수집 프로그램이 아닙니다. 웹 수집·시각 검토·사이트 갱신에는 실행 환경의 도구와 접근 권한이 필요합니다. 로그인이나 접근 제한을 우회하지 않으며, 새 블로그·저장소에 대한 게시 권한을 부여하지 않습니다.
