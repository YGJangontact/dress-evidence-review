# 공유 파일 구성

- `article.md`: 실제 작업 과정을 정리한 글. 외부 게시 전 원고 확인용.
- `dress-evidence-review/`: 재사용 가능한 Codex 스킬.
- 개인 피팅 사진·손글씨 원본·인스타그램 사진·계정 토큰은 포함하지 않았습니다.

## 설치

ZIP을 풀고 `dress-evidence-review` 폴더를 자신의 Codex 스킬 폴더에 복사합니다. 기본 위치는 현재 Codex 문서 기준 `~/.agents/skills/`이고, 예전 버전은 `~/.codex/skills/`입니다. 같은 이름의 폴더가 있으면 먼저 내용을 비교합니다. 스킬 목록에 나타나지 않으면 새 대화에서 확인합니다.

## 호출

```text
$dress-evidence-review
첨부한 기록 두 장은 두 사람이 같은 네 벌을 기록한 것이다.
업체별 피팅 순서를 유지하고, 두 사람의 의견을 구분해 전사해줘.
실제 사진과 외부 후보를 구별하고 원본 전체보기와 출처를 남겨줘.
```

외부 게시물 수집이나 사이트 갱신에는 해당 환경의 브라우저·연결 도구와 접근 권한이 필요합니다. 이 스킬 자체가 자동 스크래퍼나 게시 권한을 제공하지는 않습니다.

## 검토 기록 검사

`references/review-records.md`의 형식으로 기록을 만든 뒤 실행합니다.

```sh
python dress-evidence-review/scripts/check_review.py review.json
```

검사 결과가 정상이어도 사진의 동일성이나 사람의 판독 정확성을 보장하지 않습니다. 도구는 중복과 완료 상태의 모순을 확인합니다.
